# New Account Guide

## Welcome

Your account works, but you can only edit your own pages until an admin gives you the Player role. You can already read the whole wiki and join any discussion.

The wiki is a private MediaWiki site for our homebrew game, the same software that runs Wikipedia. Only signed-in members can read it, apart from the Main Page, which anyone can see. Pages are written in a light markup called *wikitext*, which MediaWiki turns into HTML.

These are the roles on the wiki:

| Role | What they can do |
| --- | --- |
| **New account** (you) | Edit their own user pages and post on any talk page |
| Player | Suggest edits on any page and upload files up to 20 MB |
| Loremaster | Everything a Player can, plus approve, move, protect, patrol, block, bulk edit and upload files up to 99 MB |
| Admin | Templates, forms and modules, deleting pages, giving out the Player and Loremaster roles, interwiki prefixes |
| Site developer | Site-wide CSS and JavaScript, such as `MediaWiki:Common.css` |

## Getting the Player role

Admins are told in Discord automatically when someone signs up. To speed things up, post your wiki username in Discord so they know the account is yours. Once you have the role, read the [Player Guide](player.md).

## What you can do now

| Action | Where |
| --- | --- |
| Read every page | Anywhere on the wiki |
| Create and edit your own pages | `User:YourName` and any page under it, such as `User:YourName/Thorn` |
| Post on any talk page | The **Discussion** tab on any page |
| Watch pages and get notifications | Star icon, and the bell |
| Thank editors | **thank** link in a page's history |
| Set up your account | `Special:Preferences` and `Special:OATHManage` |

Until you're a Player, you can't edit other pages, create pages outside your user space or upload files. The wiki tells you so if you try.

## Start your character now

You don't have to wait for the role to start writing.

1. Go to `Special:MyPage` and click **Create** to make your user page. A line or two about yourself is plenty.
2. Create a draft page under it, such as `User:YourName/Thorn`, and write your character's backstory there.
3. Once you're a Player, make the real character page with the **Create or edit character** box on `Category:Characters`. Paste your backstory into the large box below the form.

Your user pages never need approval, and every member can read them.

## Your account

- Passwords must be at least 12 characters. Three wrong attempts lock you out for 15 minutes.
- Email is turned off, so there is no "forgot password" link. Write your password down somewhere safe, or ask an admin to reset it.
- Two-factor login is optional: `Special:OATHManage`.
- The skin follows your device's light or dark mode. You can switch to light, dark or auto in the skin's own settings panel.
- The wiki allows one new account per network. If a friend on the same home network can't sign up, an admin can create the account for them.

## Formatting basics

| You write | You get |
| --- | --- |
| `== Section ==` | A heading |
| `''italic''` | *italic* |
| `'''bold'''` | **bold** |
| `* item` | A bullet list |
| `# item` | A numbered list |
| `[[Thornwall]]` | A link to the page Thornwall |
| `[[Thornwall\|the old keep]]` | The same link with different text |
| `~~~~` | Your signature, for talk pages |

The [Player Guide](player.md) has the full cheat sheet, including tables, images and styling with HTML and CSS.

## Good manners

- Sign your talk page posts. The **Reply** button does it for you.
- Don't copy text or images from books, other wikis or the web.
- Ask questions on talk pages. Loremasters and admins are there to help.
